# Skill: Frontend Iteration

**Description:**
Use this skill whenever the task involves modifying frontend code, UI components, or styling.

**Instructions:**
*   **Frontend Focus Only:** Confine all your modifications strictly to frontend files (e.g., HTML, CSS, frontend JavaScript/TypeScript, React/Vue/Angular components). Do not touch backend logic or API routes.
*   **No Visual Verification:** You are strictly forbidden from attempting to run the dev server, opening a browser, taking screenshots, or trying to visually self-verify your changes.
*   **Pause for User Feedback:** Once you have written and saved the frontend code modifications, immediately stop. Wait for the user to manually test the changes and provide you with feedback or the next steps.
